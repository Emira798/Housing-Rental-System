房屋模块功能文档

一、数据库与实体类设计

1. 房屋表（house）：
   id：整数类型，主键，自增长，房屋唯一标识
   title：字符串类型，非空，房屋标题
   description：字符串类型，房屋描述
   area：小数类型，非空，房屋面积（平方米）
   price：小数类型，非空，租金价格（元/月）
   address：字符串类型，非空，房屋地址
   type_id：整数类型，非空，外键，关联房屋类型表
   landlord_id：整数类型，非空，外键，关联用户表，房东ID
   status：整数类型，非空，房屋状态（0-下架，1-待出租，2-已出租）
   images：字符串类型，房屋图片（JSON格式存储图片路径数组）
   facilities：字符串类型，配套设施（JSON格式存储设施信息）
   create_time：日期时间类型，创建时间
   update_time：日期时间类型，更新时间

2. 房屋类型表（house_type）：
   id：整数类型，主键，自增长，类型唯一标识
   name：字符串类型，非空，唯一，类型名称
   description：字符串类型，类型描述
   create_time：日期时间类型，创建时间
   update_time：日期时间类型，更新时间

3. 实体类定义：
   House类：对应房屋表，包含房屋基本信息属性

二、房屋管理功能

功能概述：
系统提供房屋管理功能，包括房屋列表查询、添加、编辑、删除、上下架等操作。管理员可以管理所有房屋信息，房东用户只能管理自己发布的房屋信息。

实现流程：
1. 后台加载房屋管理页面时，请求后端分页接口获取房屋列表数据
2. 支持按房屋标题、价格范围、类型、状态等条件筛选
3. 提供添加房屋、编辑房屋、删除房屋、上下架房屋等操作按钮
4. 点击相应按钮执行对应操作
5. 支持房屋图片上传和预览
6. 支持导出房屋列表为Excel文件

功能实现细节：
1. 房屋列表管理界面：
   - 表格顶部提供搜索区域，包含以下筛选条件：
     - 房屋标题：支持模糊搜索
     - 价格范围：支持设置最低价和最高价
     - 房屋类型：支持按房屋类型筛选
     - 房屋状态：支持按状态筛选（下架、待出租、已出租）
   - 表格展示房屋主要信息：
     - 序号
     - 房屋标题
     - 面积
     - 价格
     - 地址
     - 房屋类型
     - 房屋图片（显示缩略图）
     - 房东
     - 状态
     - 创建时间
     - 操作按钮
   - 操作按钮根据房屋状态动态显示：
     - 编辑：所有状态都可编辑
     - 下架：待出租或已出租状态可下架
     - 上架：下架状态可上架
     - 删除：非已出租状态可删除

2. 房屋添加功能：
   - 弹出添加房屋对话框
   - 表单包含必填字段验证（标题、面积、价格、地址、类型、描述）
   - 支持上传多张房屋图片（限制图片格式和大小）
   - 支持选择配套设施（WiFi、电梯、空调、洗衣机、冰箱、电视、热水器）
   - 可设置初始状态（下架或待出租）

3. 房屋编辑功能：
   - 弹出编辑房屋对话框，预填充房屋当前信息
   - 支持修改房屋基本信息、图片和配套设施
   - 编辑时可以添加或删除图片
   - 编辑时可以修改配套设施选项

4. 删除功能：
   - 点击删除按钮，弹出确认对话框
   - 删除操作不可恢复，会从数据库中永久删除房屋数据
   - 已出租状态的房屋不允许删除

5. 图片管理功能：
   - 支持上传多张房屋图片
   - 支持预览和删除已上传图片
   - 图片格式限制为常见图片格式（JPG、PNG等）
   - 图片大小限制为5MB以内

6. 权限控制：
   - 管理员可以管理所有房屋
   - 房东只能管理自己发布的房屋
   - 系统自动识别当前用户角色，过滤数据权限

7. 数据导出功能：
   - 支持将当前筛选条件下的房屋列表导出为Excel文件
   - 导出文件包含房屋主要信息字段
   - 导出时自动设置合适的列宽

8. 房屋状态管理：
   - 通过不同颜色标签显示房屋状态（灰色-下架，绿色-待出租，黄色-已出租）
   - 点击"上架/下架"按钮可切换房屋状态
   - 状态变更立即生效，影响房屋在前台的展示

}

@Transactional
public void updateHouseStatus(Long id, Integer status) {
    // 获取当前登录用户
    User currentUser = JwtTokenUtils.getCurrentUser();
    if (currentUser == null) {
        throw new ServiceException("获取当前用户信息失败");
    }
    
    // 检查房屋是否存在
    House existingHouse = houseMapper.selectById(id);
    if (existingHouse == null) {
        throw new ServiceException("房屋不存在");
    }
    
    // 检查权限：只有管理员或房东可以修改
    if (!"ADMIN".equals(currentUser.getRoleCode()) && !currentUser.getId().equals(existingHouse.getLandlordId())) {
        throw new ServiceException("无权修改该房屋状态");
    }
    
    // 检查状态值是否有效
    if (status < 0 || status > 2) {
        throw new ServiceException("无效的房屋状态值");
    }
    
    House house = new House();
    house.setId(id);
    house.setStatus(status);
    house.setUpdateTime(LocalDateTime.now());
    
    int result = houseMapper.updateById(house);
    if (result <= 0) {
        throw new ServiceException("更新房屋状态失败");
    }
}
