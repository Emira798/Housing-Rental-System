租赁记录和收支明细模块功能文档

一、租赁记录模块

1. 数据库与实体类设计

1.1 租赁记录表（lease_record）：
   id：整数类型，主键，自增长，租赁记录唯一标识
   order_id：整数类型，非空，外键，关联订单表
   house_id：整数类型，非空，外键，关联房屋表
   tenant_id：整数类型，非空，外键，关联用户表，租客ID
   landlord_id：整数类型，非空，外键，关联用户表，房东ID
   start_date：日期类型，非空，租期开始日期
   end_date：日期类型，非空，租期结束日期
   rent_amount：小数类型，非空，租金金额
   payment_cycle：字符串类型，非空，支付周期（MONTHLY/QUARTERLY/YEARLY）
   status：整数类型，非空，状态（0-已取消，1-租赁中，2-已结束，3-已退租）
   actual_end_date：日期类型，实际结束日期
   contract_url：字符串类型，合同文件URL
   evaluation_score：整数类型，评价分数（1-5）
   evaluation_content：字符串类型，评价内容
   create_time：日期时间类型，创建时间
   update_time：日期时间类型，更新时间

1.2 实体类定义：
   LeaseRecord类：对应租赁记录表，包含租赁记录基本信息属性

2. 租赁记录创建功能

功能概述：
系统提供租赁记录创建功能，当订单确认后，自动创建租赁记录并生成租赁合同。租赁记录包含租期信息、租金金额、支付周期等关键信息，关联订单、房屋、租客和房东。

实现流程：
1. 订单确认后，调用租赁记录服务的创建方法
2. 获取相关的房屋、租客、房东信息
3. 创建租赁记录，设置租期、租金和支付周期
4. 生成租赁合同
5. 保存租赁记录到数据库

关键代码示例：
【springboot/src/main/java/org/example/springboot/service/LeaseRecordService.java：创建租赁记录】
@Transactional
public LeaseRecord createLeaseRecord(Order order) {
  // 查询相关信息
  House house = houseMapper.selectById(order.getHouseId());
  User tenant = userMapper.selectById(order.getTenantId());
  User landlord = userMapper.selectById(order.getLandlordId());
  
  if (house == null || tenant == null || landlord == null) {
    throw new ServiceException("创建租赁记录失败：缺少必要信息");
  }
  
  // 创建租赁记录
  LeaseRecord leaseRecord = new LeaseRecord();
  leaseRecord.setOrderId(order.getId());
  leaseRecord.setHouseId(house.getId());
  leaseRecord.setTenantId(tenant.getId());
  leaseRecord.setLandlordId(landlord.getId());
  
  // 设置租期
  LocalDate startDate = LocalDate.now();
  LocalDate endDate = startDate.plusMonths(defaultContractDuration);
  leaseRecord.setStartDate(startDate);
  leaseRecord.setEndDate(endDate);
  
  // 设置租金和支付周期
  leaseRecord.setRentAmount(house.getPrice());
  leaseRecord.setPaymentCycle("MONTHLY"); // 默认月付
  
  // 设置初始状态为租赁中
  leaseRecord.setStatus(1);
  
  // 生成合同
  String contractUrl = contractGenerator.generateContract(leaseRecord, order, house, tenant, landlord);
  leaseRecord.setContractUrl(contractUrl);
  
  // 保存租赁记录
  leaseRecordMapper.insert(leaseRecord);
  
  return leaseRecord;
}

3. 合同生成功能

功能概述：
系统提供合同生成功能，根据租赁记录、订单、房屋、租客和房东信息生成租赁合同，并提供手动重新生成合同的功能。合同以PDF格式保存，可供用户下载。

实现流程：
1. 房东或管理员点击"生成合同"按钮
2. 系统验证用户权限
3. 获取租赁记录及相关信息
4. 调用合同生成器生成PDF合同
5. 更新租赁记录的合同URL
6. 返回生成结果

关键代码示例：
【springboot/src/main/java/org/example/springboot/service/LeaseRecordService.java：手动生成合同】
@Transactional
public LeaseRecord generateContractForLeaseRecord(Long id) {
  LeaseRecord leaseRecord = leaseRecordMapper.selectById(id);
  if (leaseRecord == null) {
    throw new ServiceException("租赁记录不存在");
  }
  
  // 查询相关信息
  House house = houseMapper.selectById(leaseRecord.getHouseId());
  User tenant = userMapper.selectById(leaseRecord.getTenantId());
  User landlord = userMapper.selectById(leaseRecord.getLandlordId());
  Order order = orderMapper.selectById(leaseRecord.getOrderId());
  
  if (house == null || tenant == null || landlord == null || order == null) {
    throw new ServiceException("生成合同失败：缺少必要信息");
  }
  
  // 生成合同
  String contractUrl = contractGenerator.generateContract(leaseRecord, order, house, tenant, landlord);
  if (contractUrl == null) {
    throw new ServiceException("合同生成失败，请稍后重试");
  }
  
  // 更新租赁记录的合同URL
  leaseRecord.setContractUrl(contractUrl);
  leaseRecordMapper.updateById(leaseRecord);
  
  log.info("手动生成合同成功，租赁记录ID：{}，合同URL：{}", id, contractUrl);
  
  return leaseRecord;
}

public Page<LeaseRecord> getTenantLeaseRecordsByPage(Integer currentPage, Integer size, Integer status) {
  Long userId = JwtTokenUtils.getCurrentUser().getId();
  if (userId == null) {
    throw new ServiceException("获取当前用户信息失败");
  }
  
  LambdaQueryWrapper<LeaseRecord> queryWrapper = new LambdaQueryWrapper<>();
  queryWrapper.eq(LeaseRecord::getTenantId, userId);
  
  if (status != null) {
    queryWrapper.eq(LeaseRecord::getStatus, status);
  }
  
  Page<LeaseRecord> page = leaseRecordMapper.selectPage(new Page<>(currentPage, size), queryWrapper);
  
  // 加载关联信息
  for (LeaseRecord record : page.getRecords()) {
    loadAssociatedInfo(record);
  }
  
  return page;
}

@Operation(summary = "下载租赁合同")
@GetMapping("/{id}/download-contract")
public void downloadContract(@PathVariable Long id, HttpServletResponse response) {
  // 获取当前用户
  User currentUser = JwtTokenUtils.getCurrentUser();
  if (currentUser == null) {
    response.setStatus(HttpServletResponse.SC_UNAUTHORIZED);
    return;
  }
  
  // 获取租赁记录
  LeaseRecord leaseRecord = leaseRecordService.getById(id);
  if (leaseRecord == null) {
    response.setStatus(HttpServletResponse.SC_NOT_FOUND);
    return;
  }
  
  // 检查权限（只有管理员、房东和对应的租户可以下载合同）
  String roleCode = currentUser.getRoleCode();
  if (!"ADMIN".equals(roleCode) 
      && !leaseRecord.getLandlordId().equals(currentUser.getId())
      && !leaseRecord.getTenantId().equals(currentUser.getId())) {
    response.setStatus(HttpServletResponse.SC_FORBIDDEN);
    return;
  }
  
  // 检查合同是否存在
  if (StringUtils.isEmpty(leaseRecord.getContractUrl())) {
    response.setStatus(HttpServletResponse.SC_NOT_FOUND);
    return;
  }
  
  // 获取文件路径
  String contractPath = "files" + leaseRecord.getContractUrl();
  File file = new File(contractPath);
  if (!file.exists()) {
    response.setStatus(HttpServletResponse.SC_NOT_FOUND);
    return;
  }
  
  // 设置响应头
  response.setContentType("application/pdf");
  response.setHeader("Content-Disposition", "attachment; filename=contract_" + id + ".pdf");
  
  try {
    // 将文件内容写入响应流
    Files.copy(file.toPath(), response.getOutputStream());
    response.getOutputStream().flush();
  } catch (IOException e) {
    log.error("下载合同文件失败", e);
    response.setStatus(HttpServletResponse.SC_INTERNAL_SERVER_ERROR);
  }
}

【springboot/src/main/java/org/example/springboot/service/LeaseRecordService.java：评价处理】
@Transactional(rollbackFor = Exception.class)
public void evaluateLeaseRecord(Long leaseRecordId, Long userId, Integer score, String content) {
  // 获取租赁记录
  LeaseRecord leaseRecord = getById(leaseRecordId);
  if (leaseRecord == null) {
    throw new ServiceException("租赁记录不存在");
  }
  
  // 验证是否为租客本人
  if (!leaseRecord.getTenantId().equals(userId)) {
    throw new ServiceException("只有租客本人可以评价");
  }
  
  // 验证租赁状态是否为已结束
  if (leaseRecord.getStatus() != LeaseStatus.ENDED.getCode()) {
    throw new ServiceException("只有已结束的租赁才能评价");
  }
  
  // 验证评分范围
  if (score < 1 || score > 5) {
    throw new ServiceException("评分必须在1-5之间");
  }
  
  // 验证评价内容
  if (StringUtils.isEmpty(content)) {
    throw new ServiceException("评价内容不能为空");
  }
  
  // 更新租赁记录的评价信息
  leaseRecord.setEvaluationScore(score);
  leaseRecord.setEvaluationContent(content);
  updateById(leaseRecord);
  
  // 更新房屋的平均评分（可选）
  updateHouseAverageScore(leaseRecord.getHouseId());
  
  log.info("租赁记录[{}]评价成功，评分：{}，内容：{}", leaseRecordId, score, content);
}

功能实现细节：
1. 评价对话框：

public Page<Transaction> getUserTransactionsByPage(Long userId, Integer currentPage, Integer size, 
                                                  Integer type, LocalDate startDate, LocalDate endDate) {
  // 构建查询条件
  LambdaQueryWrapper<Transaction> queryWrapper = new LambdaQueryWrapper<>();
  queryWrapper.eq(Transaction::getUserId, userId);
  
  // 按交易类型筛选
  if (type != null) {
    queryWrapper.eq(Transaction::getType, type);
  }
  
  // 按时间范围筛选
  if (startDate != null) {
    queryWrapper.ge(Transaction::getCreateTime, startDate.atStartOfDay());
  }
  if (endDate != null) {
    queryWrapper.le(Transaction::getCreateTime, endDate.plusDays(1).atStartOfDay());
  }
  
  // 按创建时间降序排序
  queryWrapper.orderByDesc(Transaction::getCreateTime);
  
  // 分页查询
  Page<Transaction> page = transactionMapper.selectPage(new Page<>(currentPage, size), queryWrapper);
  
  // 加载关联信息
  for (Transaction transaction : page.getRecords()) {
    loadAssociatedInfo(transaction);
  }
  
  return page;
}

public TransactionStatisticsVO getUserTransactionStatistics(Long userId, LocalDate startDate, 
                                                           LocalDate endDate, String groupBy) {
  // 设置默认时间范围（如果未指定）
  if (startDate == null) {
    startDate = LocalDate.now().minusMonths(6);
  }
  if (endDate == null) {
    endDate = LocalDate.now();
  }
  
  // 构建统计对象
  TransactionStatisticsVO statistics = new TransactionStatisticsVO();
  
  // 计算总收入
  BigDecimal totalIncome = calculateTotalAmount(userId, TransactionType.INCOME.getCode(), startDate, endDate);
  statistics.setTotalIncome(totalIncome);
  
  // 计算总支出
  BigDecimal totalExpense = calculateTotalAmount(userId, TransactionType.EXPENSE.getCode(), startDate, endDate);
  statistics.setTotalExpense(totalExpense);
  
  // 计算净收入
  statistics.setNetIncome(totalIncome.subtract(totalExpense));
  
  // 获取收支趋势数据
  List<TransactionTrendVO> trends = calculateTransactionTrends(userId, startDate, endDate, groupBy);
  statistics.setTrends(trends);
  
  return statistics;
}

@Transactional(rollbackFor = Exception.class)
public void addTransaction(Long userId, TransactionDTO dto) {
  // 验证交易类型
  if (dto.getType() == null || (dto.getType() != TransactionType.INCOME.getCode() 
      && dto.getType() != TransactionType.EXPENSE.getCode())) {
    throw new ServiceException("无效的交易类型");
  }
  
  // 验证交易金额
  if (dto.getAmount() == null || dto.getAmount().compareTo(BigDecimal.ZERO) <= 0) {
    throw new ServiceException("交易金额必须大于0");
  }
  
  // 验证交易描述
  if (StringUtils.isEmpty(dto.getDescription())) {
    throw new ServiceException("交易描述不能为空");
  }
  
  // 创建交易记录
  Transaction transaction = new Transaction();
  transaction.setUserId(userId);
  transaction.setType(dto.getType());
  transaction.setAmount(dto.getAmount());
  transaction.setDescription(dto.getDescription());
  transaction.setOrderId(dto.getOrderId());
  transaction.setLeaseRecordId(dto.getLeaseRecordId());
  transaction.setCreateTime(LocalDateTime.now());
  
  // 保存到数据库
  save(transaction);
  
  log.info("用户[{}]添加了一条交易记录，类型：{}，金额：{}", userId, 
      dto.getType() == TransactionType.INCOME.getCode() ? "收入" : "支出", 
      dto.getAmount());
}

- 异步处理：大批量数据处理采用异步方式，提高响应速度

7. 异常处理

7.1 前端异常处理：
- 网络错误处理：请求失败时显示友好的错误提示
- 表单验证：在提交前进行数据验证，减少无效请求
- 加载状态：显示加载中状态，提升用户体验
- 空数据处理：处理无数据情况的显示

7.2 后端异常处理：
- 业务异常：使用ServiceException封装业务逻辑错误
- 数据库异常：事务管理确保数据一致性
- 日志记录：记录异常信息，便于问题排查
- 统一响应：统一异常处理，返回标准格式的错误信息

8. 总结

租赁记录模块和收支明细模块是房屋租赁系统的核心功能模块之一，它们协同工作，共同支持系统的租赁管理和财务管理功能。

租赁记录模块负责管理租赁合同的全生命周期，包括创建租赁记录、生成合同、查看租赁详情、评价租赁体验等功能。它与订单模块、房屋模块、用户模块紧密集成，确保租赁流程的顺利进行。

收支明细模块则负责记录和管理系统中的所有财务交易，包括租金收入、支出等。它提供了收支明细的查询、统计和分析功能，帮助用户了解自己的财务状况。

这两个模块的设计和实现遵循了以下原则：
1. 功能完整性：覆盖租赁和财务管理的全流程
2. 用户体验：简洁直观的界面，便捷的操作流程
3. 数据安全：严格的权限控制和数据保护
4. 性能优化：高效的数据处理和展示
5. 可扩展性：良好的模块化设计，便于未来功能扩展

通过这两个模块的实现，系统能够有效支持房屋租赁业务的管理，提高租赁过程的效率和透明度，为用户提供便捷的租赁和财务管理体验。
